# Runmageddon PM — CV (Mateusz Kaźmierczak)

Statyczna strona aplikacyjna na stanowisko Project Managera (Runmageddon).

- Repo: https://github.com/combomanager/runmageddon-pm-cv
- Kolory brandu: `#FFDD00` / `#0F0F10`

## Vercel (zalecane)

1. Zaloguj się: `npx vercel login`
2. Import z GitHub: https://vercel.com/new/clone?repository-url=https://github.com/combomanager/runmageddon-pm-cv  
   (framework: **Other**, root: `.`, bez build command)
3. Albo z CLI w tym folderze: `npx vercel --prod`

Każdy push na `main` wdraża automatycznie po podłączeniu repozytorium w Vercel.

## GitHub Pages (alternatywa)

Pages z brancha `main` / root — URL w Settings → Pages repozytorium.
